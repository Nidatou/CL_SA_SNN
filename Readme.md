# CL Sparse-Activation SNN
This repo is a work to explore the method of continual learning in Spiking neural networks (SNNs).
The code here mainly explore the methods that do not need the rehearsal exemplars but can also reach a content result under Class-IL scenario

It is also the source code of the "Efficient Spiking Neural Networks with Sparse Selective Activation for Continual Learning"

# Running experiments
This code is used to replicate the results and part of the plot in the paper

First install the required package:
```bash
pip install -r requirements.txt
```

The experiments are conduct under MNIST, CIFAR10, CIFAR100 and N-MNIST. 
Among them, the experiments of CIFAR10 and CIFAR100 are not conducted directly on the source data, but are trained by embeddings generated by a pre-trained feature extractors. 
So for the sake of simplicity, we directly used pre-stored embeddings for training (<CIFAR-Embeddings-0>, <CIFAR100-Embeddings> in ./store/datasets).

MNIST and N-MNIST is trained under source data. 
But due to the large quantity of signal when N-MNIST is directly inputted, we deploy an extra step of down-sampling. 

Over all, the execution and comparison code under each dataset is shown in the following (ignoring the download process of single dataset):

```bash
# MNIST
python compare_MNIST.py
# CIFAR10
python compare_CIFAR10_Embeddings.py
# CIFAR100
python compare_CIFAR100_Embeddings.py
# N-MNIST
python fixed_the_NMNIST.py
python compare_NMNIST.py
```

In addition to comparison experiment, we also conduct ablation experiments and neuron-selectivity analysis to 
```bash
# Ablation experiment
python compare_CIFAR10_Embeddings_ablation.py
# Selectivity analyse
python analyse_regr_CIFAR10.py  # CIFAR10
python analyse_regr_MNIST.py  # MNIST
```
